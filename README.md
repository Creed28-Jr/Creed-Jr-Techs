# June Receipt Assistant

A simple Python receipt program for the listed products.

## Run

```powershell
python Specs.py
```

The program greets the customer, waits for a response, and prints a receipt table with the item, quantity, price, amount, and total.

## Inventory

The assistant should only use products and prices listed in the receipt table or supplied context. If a requested product is not listed or is out of sale, it should say that the product is not available instead of inventing stock or a price.
